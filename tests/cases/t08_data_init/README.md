# t08_data_init

## 목적
data.bin 초기값을 little-endian으로 읽는지 확인 (78 56 34 12 -> 0x12345678). data.bin 뒤쪽은 0으로 채워져 data.out이 1024바이트인지 확인

## 명령어

| 주소 | 기계어 | 어셈블리 |
| --- | --- | --- |
| 0x00040000 | 0x100000b7 | lui x1, 0x10000 |
| 0x00040004 | 0x0000a103 | lw x2, 0(x1) (= 0x12345678) |
| 0x00040008 | 0x0040a183 | lw x3, 4(x1) (= 0x80000001) |
| 0x0004000c | 0x0020a423 | sw x2, 8(x1) |
| 0x00040010 | 0x0030a623 | sw x3, 12(x1) |
| 0x00040014 | 0x00310233 | add x4, x2, x3 (= 0x92345679) |
| 0x00040018 | 0x0040a823 | sw x4, 16(x1) |
| 0x0004001c | 0x00000000 | invalid instruction (종료) |

## 초기 data.bin
8바이트: `7856341201000080`

## 기대 결과 도출 근거

- 표준 출력: `PC 0x0004001c invalid instruction 0x00000000`
  - 분기 없는 직선 실행을 가정해, 마지막 단어의 주소와 값으로 계산했다.
- data.out 오프셋 8: `78563412` (그 밖의 바이트는 data.bin 내용, 없으면 0)
- data.out 오프셋 12: `01000080` (그 밖의 바이트는 data.bin 내용, 없으면 0)
- data.out 오프셋 16: `79563492` (그 밖의 바이트는 data.bin 내용, 없으면 0)
