# t06_backward_branch

## 목적
음수 분기 오프셋을 이용한 반복문 실행 검증

## 명령어

| 주소 | 기계어 | 어셈블리 |
| --- | --- | --- |
| 0x00040000 | 0x10000537 | lui x10, 0x10000 |
| 0x00040004 | 0x00000093 | addi x1, x0, 0 |
| 0x00040008 | 0x00300113 | addi x2, x0, 3 |
| 0x0004000c | 0x00108093 | addi x1, x1, 1 |
| 0x00040010 | 0xfe20cee3 | blt x1, x2, -4 |
| 0x00040014 | 0x00152023 | sw x1, 0(x10) |
| 0x00040018 | 0x00000000 | invalid instruction (종료) |

## 초기 data.bin
0바이트

## 기대 결과 도출 근거

- 표준 출력: `PC 0x00040018 invalid instruction 0x00000000`
  - 분기 없는 직선 실행을 가정해, 마지막 단어의 주소와 값으로 계산했다.
- data.out 오프셋 0: `03000000` (그 밖의 바이트는 data.bin 내용, 없으면 0)
