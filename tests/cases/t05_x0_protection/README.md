# t05_x0_protection

## 목적
x0에 값을 쓰더라도 항상 0으로 유지되는지 검증

## 명령어

| 주소 | 기계어 | 어셈블리 |
| --- | --- | --- |
| 0x00040000 | 0x10000537 | lui x10, 0x10000 |
| 0x00040004 | 0x06400013 | addi x0, x0, 100 |
| 0x00040008 | 0x00700093 | addi x1, x0, 7 |
| 0x0004000c | 0x00152023 | sw x1, 0(x10) |
| 0x00040010 | 0x00000000 | invalid instruction (종료) |

## 초기 data.bin
0바이트

## 기대 결과 도출 근거

- 표준 출력: `PC 0x00040010 invalid instruction 0x00000000`
  - 분기 없는 직선 실행을 가정해, 마지막 단어의 주소와 값으로 계산했다.
- data.out 오프셋 0: `07000000` (그 밖의 바이트는 data.bin 내용, 없으면 0)
