# t08_data_empty

## 목적
data.bin 크기가 0일 때 data 메모리가 전부 0으로 시작하는지 확인

## 명령어

| 주소 | 기계어 | 어셈블리 |
| --- | --- | --- |
| 0x00040000 | 0x100000b7 | lui x1, 0x10000 |
| 0x00040004 | 0x0040a103 | lw x2, 4(x1) (data.bin이 비어 있으므로 0) |
| 0x00040008 | 0x00510113 | addi x2, x2, 5 |
| 0x0004000c | 0x0020a023 | sw x2, 0(x1) |
| 0x00040010 | 0x00000000 | invalid instruction (종료) |

## 초기 data.bin
0바이트

## 기대 결과 도출 근거

- 표준 출력: `PC 0x00040010 invalid instruction 0x00000000`
  - 분기 없는 직선 실행을 가정해, 마지막 단어의 주소와 값으로 계산했다.
- data.out 오프셋 0: `05000000` (그 밖의 바이트는 data.bin 내용, 없으면 0)
