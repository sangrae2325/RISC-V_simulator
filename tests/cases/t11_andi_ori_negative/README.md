# t11_andi_ori_negative

## 목적
andi와 ori에서 음수 즉시값의 부호 확장 및 비트 연산 검증

## 명령어

| 주소 | 기계어 | 어셈블리 |
| --- | --- | --- |
| 0x00040000 | 0x10000537 | lui x10, 0x10000 |
| 0x00040004 | 0x00500093 | addi x1, x0, 5 |
| 0x00040008 | 0xfff0f113 | andi x2, x1, -1 |
| 0x0004000c | 0xfff06193 | ori x3, x0, -1 |
| 0x00040010 | 0x00252023 | sw x2, 0(x10) |
| 0x00040014 | 0x00352223 | sw x3, 4(x10) |
| 0x00040018 | 0x00000000 | invalid instruction (종료) |

## 초기 data.bin
0바이트

## 기대 결과 도출 근거

- 표준 출력: `PC 0x00040018 invalid instruction 0x00000000`
  - 분기 없는 직선 실행을 가정해, 마지막 단어의 주소와 값으로 계산했다.
- data.out 오프셋 4: `ffffffff` (그 밖의 바이트는 data.bin 내용, 없으면 0)
