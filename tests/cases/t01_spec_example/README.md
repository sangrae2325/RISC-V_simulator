# t01_spec_example

## 목적
명세서 7절 기능 확인 예시: lui, addi, add, sw와 종료 출력 형식

## 명령어

| 주소 | 기계어 | 어셈블리 |
| --- | --- | --- |
| 0x00040000 | 0x100000b7 | lui x1, 0x10000 |
| 0x00040004 | 0x00700113 | addi x2, x0, 7 |
| 0x00040008 | 0x00500193 | addi x3, x0, 5 |
| 0x0004000c | 0x00310233 | add x4, x2, x3 |
| 0x00040010 | 0x0040a023 | sw x4, 0(x1) |
| 0x00040014 | 0x00000000 | invalid instruction (종료) |

## 초기 data.bin
0바이트

## 기대 결과 도출 근거

- 표준 출력: `PC 0x00040014 invalid instruction 0x00000000`
  - 분기 없는 직선 실행을 가정해, 마지막 단어의 주소와 값으로 계산했다.
- data.out 오프셋 0: `0c000000` (그 밖의 바이트는 data.bin 내용, 없으면 0)
