# t10_funct3_bltu

## 목적
opcode는 지원 명령어와 같지만 funct3/funct7 조합이 표에 없는 명령어를 invalid로 보고 즉시 종료하는지. 뒤의 sw가 실행되지 않아 오프셋 4는 0이어야 함

## 명령어

| 주소 | 기계어 | 어셈블리 |
| --- | --- | --- |
| 0x00040000 | 0x10000537 | lui x10, 0x10000 (x10 = 0x10000000) |
| 0x00040004 | 0x00700093 | addi x1, x0, 7 |
| 0x00040008 | 0x00500113 | addi x2, x0, 5 |
| 0x0004000c | 0x002081b3 | add x3, x1, x2 (x3 = 12) |
| 0x00040010 | 0x00352023 | sw x3, 0(x10) |
| 0x00040014 | 0x0020e463 | bltu x1, x2, +8 (opcode 0x63, funct3=6: funct3가 표에 없음) -> 여기서 종료 |
| 0x00040018 | 0x00152223 | sw x1, 4(x10) (실행되면 안 됨) |
| 0x0004001c | 0x00000000 | invalid instruction (종료) |

## 초기 data.bin
0바이트

## 기대 결과 도출 근거

- 표준 출력: `PC 0x00040014 invalid instruction 0x0020e463`
- data.out 오프셋 0: `0c000000` (그 밖의 바이트는 data.bin 내용, 없으면 0)
