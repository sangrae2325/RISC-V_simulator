# t07_lw_sw

## 목적
lw/sw: 음수·양수 offset, 여러 주소(맨 앞 0x10000000, 중간, 맨 끝 0x100003fc), little-endian 저장 순서, lw로 읽은 값을 다시 사용

## 명령어

| 주소 | 기계어 | 어셈블리 |
| --- | --- | --- |
| 0x00040000 | 0x100000b7 | lui x1, 0x10000 |
| 0x00040004 | 0x10008093 | addi x1, x1, 0x100 (x1 = 0x10000100) |
| 0x00040008 | 0x12345137 | lui x2, 0x12345 |
| 0x0004000c | 0x67810113 | addi x2, x2, 0x678 (x2 = 0x12345678) |
| 0x00040010 | 0xfe20ae23 | sw x2, -4(x1) |
| 0x00040014 | 0xfff00193 | addi x3, x0, -1 |
| 0x00040018 | 0x0030a023 | sw x3, 0(x1) |
| 0x0004001c | 0x0020a423 | sw x2, 8(x1) |
| 0x00040020 | 0xffc0a203 | lw x4, -4(x1) |
| 0x00040024 | 0x00120213 | addi x4, x4, 1 |
| 0x00040028 | 0xf040a023 | sw x4, -256(x1) (data 맨 앞) |
| 0x0004002c | 0x0000a283 | lw x5, 0(x1) |
| 0x00040030 | 0x2e50ae23 | sw x5, 764(x1) (data 맨 끝 0x100003fc) |
| 0x00040034 | 0x00000000 | invalid instruction (종료) |

## 초기 data.bin
0바이트

## 기대 결과 도출 근거

- 표준 출력: `PC 0x00040034 invalid instruction 0x00000000`
  - 분기 없는 직선 실행을 가정해, 마지막 단어의 주소와 값으로 계산했다.
- data.out 오프셋 252: `78563412` (그 밖의 바이트는 data.bin 내용, 없으면 0)
- data.out 오프셋 256: `ffffffff` (그 밖의 바이트는 data.bin 내용, 없으면 0)
- data.out 오프셋 264: `78563412` (그 밖의 바이트는 data.bin 내용, 없으면 0)
- data.out 오프셋 0: `79563412` (그 밖의 바이트는 data.bin 내용, 없으면 0)
- data.out 오프셋 1020: `ffffffff` (그 밖의 바이트는 data.bin 내용, 없으면 0)
