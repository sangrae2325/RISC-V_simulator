# t03_signed_branch

## 목적
blt와 bge의 signed 비교 검증

## 명령어

| 주소 | 기계어 | 어셈블리 |
| --- | --- | --- |
| 0x00040000 | 0x10000537 | lui x10, 0x10000 |
| 0x00040004 | 0xfff00093 | addi x1, x0, -1 |
| 0x00040008 | 0x00100113 | addi x2, x0, 1 |
| 0x0004000c | 0x0020c463 | blt x1, x2, 8 |
| 0x00040010 | 0x06300193 | addi x3, x0, 99 |
| 0x00040014 | 0x0020d463 | bge x1, x2, 8 |
| 0x00040018 | 0x00700193 | addi x3, x0, 7 |
| 0x0004001c | 0x00352023 | sw x3, 0(x10) |
| 0x00040020 | 0x00000000 | invalid instruction (종료) |

## 초기 data.bin
0바이트

## 기대 결과 도출 근거

- 표준 출력: `PC 0x00040020 invalid instruction 0x00000000`
  - 분기 없는 직선 실행을 가정해, 마지막 단어의 주소와 값으로 계산했다.
- data.out 오프셋 0: `07000000` (그 밖의 바이트는 data.bin 내용, 없으면 0)
