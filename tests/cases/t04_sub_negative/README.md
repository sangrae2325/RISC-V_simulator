# t04_sub_negative

## 목적
sub 연산의 음수 결과가 32비트 2의 보수로 저장되는지 검증

## 명령어

| 주소 | 기계어 | 어셈블리 |
| --- | --- | --- |
| 0x00040000 | 0x10000537 | lui x10, 0x10000 |
| 0x00040004 | 0x00300093 | addi x1, x0, 3 |
| 0x00040008 | 0x00500113 | addi x2, x0, 5 |
| 0x0004000c | 0x402081b3 | sub x3, x1, x2 |
| 0x00040010 | 0x00352023 | sw x3, 0(x10) |
| 0x00040014 | 0x00000000 | invalid instruction (종료) |

## 초기 data.bin
0바이트

## 기대 결과 도출 근거

- 표준 출력: `PC 0x00040014 invalid instruction 0x00000000`
  - 분기 없는 직선 실행을 가정해, 마지막 단어의 주소와 값으로 계산했다.
- data.out 오프셋 0: `feffffff` (그 밖의 바이트는 data.bin 내용, 없으면 0)
